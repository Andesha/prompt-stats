# Coding Standards

## Style

- Keep code simple, readable, and idiomatic TypeScript.
- Prefer clear names over clever abstractions.
- Use existing project patterns before introducing new ones.
- Avoid unnecessary dependencies.

## Testing

- Add or update tests when behavior changes.
- Keep test names descriptive and focused on observable behavior.
- Run the relevant checks before considering work complete.

## Architecture

- Keep changes small and scoped to the task.
- Prefer straightforward functions and modules with a single responsibility.
- Do not introduce broad refactors unless they are required for the task.
